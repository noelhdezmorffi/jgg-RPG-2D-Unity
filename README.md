# RPG 2D

Proyecto personal desarrollado con Unity.
- Juégalo aquí: 
https://play.unity.com/es/games/cccce4fd-7c71-4f1e-844e-1cd04a2e29ca/2d-rpg

## Tecnologías

- Unity 6
- C#
- Aseprite

## Características actuales

- Movimiento en 4 direcciones
- Animaciones con Blend Tree
- Colisiones
- Tilemaps
- Orden de dibujo

## Próximamente

- Inventario
- NPC
- Sistema de combate
- Guardado
